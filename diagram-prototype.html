Geometry diagrams, drawn by code

Deterministic SVG rendering — the diagram is computed from the problem's given numbers, so it's accurate by construction. No AI image generation, no guessing at proportions.

The one hard rule

Every diagram shows only the given information — never a computed value, formula, or answer. The tutor's text still does the Socratic questioning; the image just makes the shape easier to picture. The renderer has no "answer" input, so nothing solved can leak in.
